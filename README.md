# belajar-github

Repo pertama Thalib buat belajar GitHub dan API.

## GitHub itu apa?

GitHub itu tempat simpan kode, seperti Google Drive khusus programmer.

- Simpan kode biar aman, kalau laptop rusak kodenya tetap ada.
- Setiap simpan dicatat versinya, jadi bisa balik ke versi lama kalau error.
- Bisa kerja bareng teman tanpa saling timpa file.

Git = aplikasi yang dipasang di laptop.
GitHub = websitenya, tempat simpan online di github.com.

## API itu apa?

API itu penghubung antar aplikasi, seperti pelayan di restoran.

Kamu pesan ke pelayan, pelayan ambil ke dapur, lalu bawain makanannya.
Kamu tidak perlu masuk dapur sendiri.

Contoh: aplikasi cuaca minta data ke server lewat API, login pakai Google juga lewat API.
